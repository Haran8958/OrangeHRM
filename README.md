#ReadMe
A robust and scalable test automation framework built using Selenium WebDriver, Java, and TestNG, following the Page Object Model (POM) design pattern.
The framework is designed with a modular and maintainable architecture to support UI test automation, reusable utilities, centralized configuration, logging, test reporting, screenshots, and automated test execution.

🚀 Key Features
Selenium WebDriver for browser automation
Java as the programming language
TestNG for test execution and test management
Page Object Model (POM) for maintainable page-level automation
Reusable Utility Classes for common automation operations
Centralized configuration using properties/config files
Custom Base Class for common test setup and teardown
ITestListener implementation for test execution monitoring
Automated screenshots for failed test cases
Log4j2 Logger for detailed execution logs
Explicit waits for reliable synchronization
Reusable WebDriver and wait utilities
Data-driven testing support
Assertions using TestNG
Maven for dependency and build management
TestNG XML suite configuration
Clean separation between test cases, page classes, utilities, and configuration
Designed for easy scalability and future CI/CD integration
